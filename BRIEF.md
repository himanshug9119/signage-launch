## 3. Brand identity

Colors were taken from the site's MUI CSS variables and computed styles.

| Role | HEX | Where it's used |
|---|---|---|
| **Primary** | `#3B82F6` (blue-500) | Buttons, logo icon (`--accent`), links, stat numbers |
| Primary dark | `#2563EB` | End of the H1 gradient; hover |
| **Secondary / accent** | `#10B981` (emerald) | "Try it live", "Online" pill, "Save 20%", savings text, ticks. It's the second most-used colour on the page. |
| Alert accent | `#EF4444` (red) | "ACTIVATE" emergency button |
| Warning accent | `#F59E0B` (amber) | Small badges |
| **Background (light)** | `#F8FAFC`; cards `#FFFFFF`; soft panels `#F1F5F9`; borders `#E2E8F0` / `rgba(15,23,42,0.08)` | |
| **Text** | `#0F172A` (headings); `#475569` (body); `#94A3B8` (muted) | |
| **Background (dark mode)** | `#0B0F1A`; cards `#111827`; text `#F1F5F9` / `#94A3B8` | |

**Gradients:**
- Light H1: `linear-gradient(to right, #0F172A 30%, #2563EB 100%)`
- Dark H1: `linear-gradient(to right, #FFFFFF 40%, #93C5FD 100%)`
- Hero glow: radial `rgba(59,130,246,0.08)` at the top right plus `rgba(16,185,129,0.03)` at the bottom left
- Accent wash: `linear-gradient(135deg, rgba(59,130,246,0.2), rgba(16,185,129,0.1))`

(MUI's default `secondary #9c27b0` purple exists in the CSS but isn't used visually. Ignore it.)

**Theme:** light by default. A dark mode follows the system setting and has a navbar toggle. Both look good. **Suggestion:** use dark for the video's intro and outro and light screenshots for the product scenes, or stick to dark throughout for a "tech launch" feel. `01b-hero-dark.png` is provided.

**Fonts:**
- **Inter** for everything (Google Fonts, weights 300–700; headings render at 800).
- H1: 56px / 800. H2: 36px / 800. Body: 18px / 400. Eyebrow labels: small, uppercase, letter-spaced, blue.

**Logo:**
- An icon plus a wordmark. The icon is the Material "Tv" outline (a monitor on a stand) in `#3B82F6`. The wordmark "ScreenSetu" is set in Inter Bold (700), colour `#0F172A` (white in dark mode).
- No standalone logo file is served, so I rebuilt it as **`logo.svg`** from the site's own navbar SVG path.
  - Icon path (24×24 viewBox): `M21 3H3c-1.1 0-2 .9-2 2v12c0 1.1.9 2 2 2h5v2h8v-2h5c1.1 0 1.99-.9 1.99-2L23 5c0-1.1-.9-2-2-2m0 14H3V5h18z`
- ⚠️ `https://screensetu.com/favicon.svg` is a blue rounded square with a white **"T"**, which doesn't match the brand. **Don't use it as the logo.**
- ⚠️ The logo and social-image URLs in the site's metadata (`/assets/logo.png`, `/assets/og-image.png`) return the homepage HTML instead of an image, so they're broken. Don't reference them.

**Vibe (3 adjectives):** clean, reliable, operational. It's a calm SaaS look: lots of white space, slate text, one confident blue, and green for "online/good".

## 5. Video storyboard — 60 seconds

**Spec suggestion:** 1920×1080, 30 fps, 1800 frames. Make a 1080×1920 vertical cut later for Reels/Shorts, using the mobile screenshots.
**Style:** Inter 800 headlines, `#0F172A` / `#0B0F1A` backgrounds, `#3B82F6` primary, `#10B981` for "online/success" moments, `#EF4444` only for the takeover beat. Screenshots go inside a floating browser-frame mockup with soft shadow, slow push-ins (1.00→1.06), and a subtle parallax.

| Time | Scene | Visual | On-screen text |
|---|---|---|---|
| 0–3s | **Hook** | Dark screen. A grid of 6 TV outlines; one flickers to black, another shows "Yesterday's offer". Glitch sound. | "Blank screens. Stale content." |
| 3–6s | Hook, part 2 | A USB stick icon and a delivery van slide in, then get crossed out. | "No truck roll. No USB sticks." (site wording) |
| 6–11s | **Logo reveal** | The TV icon draws its outline in `#3B82F6`, the screen fills with a blue→emerald glow, and the "ScreenSetu" wordmark types in. | "DIGITAL SIGNAGE THAT JUST WORKS" (eyebrow), then the tagline "Every screen in your business, under your control." |
| 11–16s | Feature 1: one dashboard | `01-hero.png` in a browser frame; 6 TV tiles orbit in and snap into a grid. | "Every screen. One dashboard." |
| 16–21s | Feature 2: instant updates | `02-emergency-takeover-card.png` (Online pill). A "Save" click fires a pulse line to 3 TVs that swap content, with a counter ticking to "< 2s". | "Hit save. Live in under 2 seconds." |
| 21–26s | Feature 3: scheduling | `03-features.png`, zoomed on the "Smart scheduling & dayparting" card. A day-timeline (Breakfast → Lunch → Dinner) swaps a menu board. | "Right content, right hour, every day." |
| 26–31s | Feature 4: emergency takeover | Card crop zooms into the red **ACTIVATE** button; click; every TV in the grid flashes red "ALERT", then restores. Screen shake and alert sting. | "One click overrides every screen." |

| 36–41s | Feature 6: live health | `04-features-all.png`; animated status rows (Online ●, CPU, uptime) with a "Restart player" button click. | "Uptime, CPU, restarts — from your desk." |
| 41–46s | Feature 7: hardware | `06-hardware.png`; device chips (Android TV, Google TV, HDMI sticks, Samsung Tizen) fly in. | "No new hardware. Use what you own." |
| 46–51s | How it works | `05-how-it-works.png`; the 01 → 02 → 03 steps light up in sequence. | "Pair. Build. Go live." |

**Music mood:** upbeat, modern electronic / tech-corporate at about **120 BPM**.
- 0–6s: tense, filtered intro with a glitch hit.
- 6s: a clean drop on the logo reveal.
- 26s: a short alarm sting on the emergency takeover, then the beat returns.
- 55s: resolve on a bright final chord.

**SFX:** UI clicks, soft whooshes between scenes, a "ping" on each live update.
